1. 原：网络有*实际使用带宽*、*当前已使用带宽*
   改：保留*当前已使用带宽*表示已在运行的任务使用的带宽，删去*实际使用带宽*
2. 增：当前已在运行的任务必须完成
3. 原：负载均衡 $\min \frac{1}{|W \cup W_{new}|} \sum_{w \in W \cup W_{new}} (\alpha_w - \bar{\alpha})^2$
   改：$\min \frac{1}{|W \cup W_{new}|} \sum_{w \in W \cup W_{new}} |\alpha_w - \bar{\alpha}|$
4. 原：*是否为网关节点*作为输入
   改：*是否为网关节点*由加入的网络个数判断







```bash
curl -X POST http://127.0.0.1:861/run \
     -H "Content-Type: application/json" \
     -d @data.json
```





## 输入格式

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| `w1` | `float` | 总成本的权重，`w1+w2+w3=1` |
| `w2` | `float` | 总带宽的权重，`w1+w2+w3=1` |
| `w3` | `float` | 负载均衡的权重，`w1+w2+w3=1` |
| `list_wangluo` | `array<wangluo>` | 网络对象数组，见下方`wangluo`结构 |
| `list_ziyuan` | `array<ziyuan>` | 资源对象数组，见下方`ziyuan`结构 |
| `list_renwu` | `array<renwu>` | 任务对象数组，见下方`renwu`结构 |

### `wangluo` 对象

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| `num_shebei` | `integer`       | 当前网络内部的设备数量                       |
| `list_shebei` | `array<shebei>` | 当前网络包含设备对象数组，见下方`shebei`结构 |
| `latency` | `float` | 网络时延 |
| `bandwidth` | `float` | 网络带宽 |
| `list_normal_bian` | `array<normal_bian>` | 网内边的集合，见下方`normal_bian`结构 |
| `id` | `string` | 网络ID |
| `now_bandwidth` | `float` | 当前已使用带宽 |

### `shebei`对象

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| `id`                   | `string` | 设备ID                     |
| `name`                 | `string` | 设备名称                   |
| `is_gateway` | `boolean` | 是否为网关节点 |
| `max_concurrent_tasks` | `integer` | 最多允许多少个任务同时使用 |

### `ziyuan`对象

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| `id`                   | `string` | 设备ID                     |
| `name`                 | `string` | 设备名称                   |
| `list_wangluo` | `array<string>` | 可加入的网络列表，网络由其ID表示 |
| `acost` | `float` | 使用成本 |
| `list_normal_bian`     | `array<normal_bian>` | 通联关系的边的集合，见下方`normal_bian`结构 |
| `max_concurrent_tasks` | `integer` | 最多允许多少个任务同时使用 |

### `renwu`对象

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| `priority`      | `integer` | 优先级，按1-3分级，数值越高，优先级越高 |
| `source_id`     | `string`  | 源平台ID                                |
| `target_id`     | `string`  | 目标平台ID                              |
| `max_latency`   | `float`   | 最大允许时延                            |
| `min_bandwidth` | `float`   | 最小可用带宽                            |
| `id`            | `string`  | 任务ID                                  |
| `name`          | `string`  | 任务名称                                |
| `finish` | `boolean` | 当前任务是否正在运行 |
| `list_bian` | `array<bian>` | 任务方案数组，见下方`bian`结构；`finish=0`时为`null` |

### `normal_bian`对象

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| `source_id` | `string` | 源平台ID   |
| `target_id` | `string` | 目标平台ID |

### `bian`对象

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| `source_pid` | `string` | 源平台ID   |
| `source_wid` | `string` | 源网络ID |
| `target_pid` | `string` | 目标平台ID |
| `target_wid` | `string` | 目标网络ID |
